# docs/experiments/ — the experiment record

Every experiment in this programme was pre-registered before it ran. This folder holds those
documents, what each experiment found, and the generated indexes that tie them to their results.

| file | what it is |
|---|---|
| [`REGISTRY.md`](REGISTRY.md) | **start here if a name is unfamiliar.** One canonical ID per experiment (`E##`) and one per run (`E##.n`), with every old ID it replaces, its documents, scripts, reproduction modules and paper tables. Generated from [`registry.json`](registry.json) by `tools/build_registry.py` |
| [`preregs/`](preregs/) | one document per pre-registered experiment: the decision rule as registered, the design, the controls with the values they produced, and the verdict |
| [`descriptions/`](descriptions/) | longer per-experiment write-ups: what was actually run, in detail |
| [`INDEX.md`](INDEX.md) | every pre-registration, its own results file, the stored verdict, and each cited file's hash. Generated by `tools/build_provenance.py` |
| [`READOUT_DEFECT.md`](READOUT_DEFECT.md) | the readout correction, stated mechanically: which items, which files, which results moved |
| [`DA1_OUTCOME.md`](DA1_OUTCOME.md) | the two layer-permutation nulls, adjudicated against their pre-registration |
| [`REGISTRATION_LEDGER.md`](REGISTRATION_LEDGER.md) | for every pre-registration, whether it was committed before, with, or after the code that computed its result |
| [`METRICS.md`](METRICS.md) | how each statistic is computed |

**About the IDs.** File names keep the IDs they were written under (`E52_factorial.md`,
`R1_grid_rstrip.md`, `CV3_margins.md`), because stored results pin them by path. Each one is a run of
exactly one experiment. `R1`, for example, is run `E52.3`: the 8 × 8 factorial re-scored at the
corrected readout. Look any ID up in [`REGISTRY.md`](REGISTRY.md).

## How to read a pre-registration

| section | what it holds |
|---|---|
| **WHY** | the question, and why it mattered at the time |
| **DESIGN** | model, corpora, *N*, band, aggregation: what varies and what is held fixed |
| **PRIMARY** | the one statistic the decision rests on |
| **DECISION RULE** | ACCEPT, REJECT or UNCLEAR, fixed before the run. It is never reinterpreted afterwards |
| **CONTROLS** | each control, the value it produced, and the value that would have made it fail. A control with no failing value could not have failed, and is labelled a recorder |
| **DECLARED BIAS** | what the author expected, written down so it can be checked against |
| **COST** | the compute it was expected to take |

Older documents add **FLAGGED DELTAS** (every known defect, amendment and open question: read this
first) and **MEANING FOR THE PAPER**. Where a stored result pins a document's exact text by SHA-256,
that version is kept byte for byte in [`preregs/as_registered/`](preregs/as_registered/), and a
document whose current text is pinned is frozen (marked in `INDEX.md`). The original registrations
for E36, E38, E48 and E52, which predate this format, are in [`preregs/superseded/`](preregs/superseded/).

## Adding an experiment

1. Take the next free number from `REGISTRY.md` (E85 at the time of writing), or a run number
   `E##.n` if it re-scores or adjudicates an existing experiment.
2. Write `preregs/E85_<name>.md` and commit it, alone, before the code that computes the result.
3. Write the script as `experiments/e85_<name>.py`, storing results with `provenance.write_result`.
4. Add a module `repro/exp/e85_<name>.sh` with the exact flags, then add the experiment to
   `registry.json` and run `tools/build_registry.py`. Its `--check` fails until every new file
   resolves.
